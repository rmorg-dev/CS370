## Question 2
### What do computer scientists do and why does it matter?
Computer Scientist solve problems using computers and related technology. Computer scientists are important because they help drive innovation in all other areas of life. Without computer science, technological advancements would advance slowly and areas regularly using technology (banking, healthcare, etc) will be more vulnerable problems like inefficient code and cyberattacks.

## Question 3
### How do I approach a problem as a computer scientist?
When approaching problems as a computer scientist, I try to break down instructions and needs into smaller steps. Once I complete each step, I combine them. If they do not work, I look at my code to first look at potential syntax errors in my code, then I look for logic errors, and finally, if it still does not work, I go back to the drawing board to see how else I could potentially solve the problem.

## Question 4
### What are my ethical responsibilities to the end user and the organization?
The ethical responsibilities I have to the end user are to protect their privacy as much as possible as well as giving them a reliable, fast experience. By creating secure and efficient code, I can make sure end users feel safe and enjoy using my product. For organizations, building secure code is of utmost importance.
